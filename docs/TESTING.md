# 验证记录与验收范围

## 自动化

使用纯合成课程数据，不含真实账号、Cookie、资源对象 ID 或签名。运行 `npm test` 查看当前测试数量与结果。

- 解析真实页面结构类型：`mArg`、iframe 元数据、单引号 `fileinfo`、直接附件与媒体。
- 模拟资源 API：原生凭据模式、同源 Referer、XHR 请求头、`download`/`pdf` 字段、HTTPS 与文件扩展名。
- 模拟目录访问：先读取章节入口，处理多卡片、未开放与身份验证状态，不执行返回 HTML 中的脚本。
- 新版首页：嵌套 `studentcourse` 目录、`toOld` 参数顺序、首页/学习页凭据区分、跨域读取、未开放与入口缺失。
- 队列：并发、暂停/继续、取消、去重、后台重建恢复、退避重试、错误 MIME、地址更新。
- 后台集成：实际注入脚本在合成 DOM 上执行，连接消息处理、资源解析、下载参数、会话来源规则和完成事件；页面按钮只能获取自身标签页，嵌入面板绑定真实来源页，跨域读取拒绝无关域名和接口。
- 安全边界：域名、协议、账号信息 URL、危险文件名、路径穿越、公开清单字段、错误脱敏、消息发起者限制。
- 入口生命周期：目录 iframe 未就绪或不可访问时仍挂载外层按钮，替换目录不产生重复按钮，页眉重绘后自动恢复入口。

这些测试模拟 Chrome API，**不等同于真实安装后的 Chrome 扩展端到端测试**。

## 已做的浏览器检查

- 在已登录的学生学习页面检查了课程目录、多层 iframe、课件元数据和云盘预览器结构。
- 验证了用户提供的资源 API 响应中，PDF 地址可以在 Chrome PDF 阅读器中正常打开；未把该地址或真实文档写入仓库。
- 检查新版课程首页的真实目录 iframe、章节行和页面现有跳转逻辑；没有将真实 HTML、参数或登录凭据存入项目。
- 在本地虚构数据预览中检查紧凑面板、批量选择与复制反馈；使用合成课程页面挂载生产入口脚本，检查按钮位置、展开/关闭和 iframe 样式隔离。该页面仅替换域名判定和 Chrome 消息传输，不代表真实扩展安装验证。
- 1.1.1 尺寸回归：在 Chrome 合成页面中从 128px 视口按内容自动扩展，对照旧样式停在 128px、新样式扩展至 460px；嵌入模式在 320px 下无横向溢出。此检查不等同于实际工具栏弹窗验收。

本地 HTTP 预览只用于界面验证；非扩展环境会显示示例提示。登录态请求、Chrome 下载权限、平台防盗链规则需要安装扩展后一起验收，不能仅凭界面示例认定成功。

## 加载后建议验收

1. 在 Chrome 中加载项目根目录，确认扩展管理页没有清单或后台错误。
2. 刷新已登录的新课程首页，确认外层页眉出现“下载课件”；从页面内面板选择章节并扫描。再在学生学习页扫描当前页，确认两种页面均可使用。切换章节目录后确认按钮仍在。
3. 复制一个 PDF 链接并粘贴到新标签页，确认内容正确。
4. 下载同一个 PDF，确认文件能打开、文件名保留中文。
5. 选择两个以上章节，目录扫描后批量下载；检查子文件夹与同名编号。
6. 暂停/继续队列，关闭管理页后检查已提交的下载是否继续。
7. 如课程有 PPT/Word，分别测试原格式和平台提供的 PDF 版。
8. 模拟过期会话或断网，确认界面提示失败，不把错误 HTML 标记为下载成功。
9. 导出 JSON 检查没有 URL、账号标识和签名；再次运行 `npm run check`。
10. 从 Chrome 工具栏打开面板，确认宽度约 460px，扫描按钮并排、章节文字正常，不被压成窄条；随后检查页面内面板仍可使用。

不同学校部署、未公开下载权限的资源、加密流媒体和第三方嵌入预览不在本次验证覆盖范围内。
