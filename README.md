# 课件收纳 · 超星课件下载助手

一个在本地浏览器中运行的 Chrome Manifest V3 扩展。从已登录的超星学生学习页面识别课件，支持选择下载、目录批量扫描、下载队列和复制链接。

**不需要填写账号或 Cookie，不需要后端服务，不需要编译即可加载。**

## 功能

- **当前页扫描**：识别跨层 iframe 中的课件元数据、云盘预览和页面附件直链。
- **目录批量扫描**：选择当前课程已开放目录中的章节，读取各章节的课件卡片；不执行返回页面的脚本。
- **多个标签页汇总**：扫描已打开的超星页面，按资源标识或文件地址去重。
- **文件筛选**：按名称、课程、章节搜索，按类型或课程筛选，全选当前筛选结果。
- **批量下载**：1–4 个并行任务，暂停/继续、取消、失败重试、下载进度、显示本地文件。
- **文件版本**：PDF 课件优先使用平台返回的 PDF 地址；PPT、Word、Excel 等默认保留原格式，也可选择平台已经生成的 PDF 版。
- **复制链接**：单个文件复制或勾选后批量复制，一行一个 URL。复制前尝试更新资源地址，与下载使用相同的版本设置。
- **自动归档**：默认保存到 `下载/超星课件/课程名/章节名/文件名`；同名自动编号，不覆盖已有文件。
- **文件清单导出**：导出 JSON，包含名称、类型、大小，不包含账号标识或下载链接。
- **会话内缓存**：关闭管理页后已提交的下载继续；浏览器会话结束后清除扩展的临时资源和队列。

支持识别 PDF、PPT/PPTX、DOC/DOCX、XLS/XLSX、常见压缩包、文本、图片及直接提供文件地址的音视频。不同课程版本和学校配置可能影响可用性。

## 安装（Chrome 120+）

1. 下载源码，或解压扩展 ZIP 到一个固定文件夹。
2. 在 Chrome 地址栏输入 `chrome://extensions`。
3. 打开右上角的 **开发者模式**。
4. 点击 **加载已解压的扩展程序**，选择包含 `manifest.json` 的文件夹。
5. 在工具栏的扩展菜单中固定“课件收纳”。

直接选择项目根目录即可使用。只有运行自动化测试时才需要 Node.js 和 `npm ci`。更新源码后，在扩展管理页点击“重新加载”，再刷新课程页面。

## 使用

### 下载当前课件

1. 正常登录超星，进入课程的“学生学习页面”，等待课件预览显示。
2. 点击扩展图标，管理页面会在新标签页中打开。
3. 选中课程来源，点击“扫描当前页”。
4. 勾选需要的文件，点击“下载所选”。

### 批量收集课程课件

点击“按目录扫描”，选择章节后开始。只有目录实际列出的可访问章节会被读取。目录尚未展开或未加载时，先在课程页展开相关目录再重试；空章节、未发布章节不保证有文件。

扫描期间保持管理页和来源课程页开启，不要把来源标签页切换到其他课程。停止按钮会在当前章节读取结束后生效。某章失败不会清空已经识别的其他文件。扫描完成后仍需勾选并发起下载。

“扫描全部已开页面”适用于资料分散在多个已登录标签页的情况。重复扫描会合并相同资源；列表最多保留 2,000 个资源，队列最多保留 2,000 个任务。

### 复制文件链接

每行有“复制链接”按钮；也可勾选多个文件后使用“复制所选链接”。复制的是实际文件 URL，不是课程页面地址。若浏览器阻止写入剪贴板，会提供可手动复制的文本框。

`download` 地址通常含短时签名，`pdf` 地址也不保证永久有效。复制链接适合个人临时使用，**不要把它们、真实请求的 cURL 或 Cookie 放进公开仓库**。清单导出刻意不导出这些链接。

### 原文件与 PDF 版

| 场景 | 默认策略 |
| --- | --- |
| PDF 课件，接口提供 `pdf` | 使用 `pdf` 地址，保持 `.pdf` 文件名 |
| PPT、Word、Excel 等 | 使用 `download` 保留原格式 |
| 在偏好中选择“文档使用 PDF 版” | 使用接口已经提供的 `pdf`，保存为 `.pdf`；不在本地进行格式转换 |
| 只有原文件，没有 PDF 转换结果 | 提示切换回原格式，不把其他格式伪装成 PDF |
| 音视频、压缩包、图片等 | 保持原文件 |

PDF 版可能是平台转换的预览副本，不保证与上传原件逐字节一致。PDF 课件采用可访问的 PDF 地址是为了提高下载成功率；不代表所有文件都应转换成 PDF。

## 工作原理

1. 用户发起扫描后，通过 `chrome.scripting` 在允许的超星页面和 iframe 中运行隔离脚本。
2. 只解析 iframe 的 `data`、`mArg.attachments`、预览页 `fileinfo` 和已有附件链接，得到 `objectid`、名称、格式等。
3. 下载或复制前，在来源页面的登录环境中 GET `/ananas/status/{objectid}?flag=normal`。请求自动使用浏览器的登录 Cookie，并带平台需要的 XHR 标识与同源文档来源；扩展代码不读取 Cookie。
4. 解析响应中的 `download` 和 `pdf`，按文件类型与用户偏好选择。签名来自平台响应，不自行生成或猜测。
5. 使用 `chrome.downloads` 保存文件；仅为当前任务的确切 URL 设置临时来源域名规则，结束后移除。

目录扫描先读取平台的章节入口，只有返回可访问课件 iframe 后才读取课件卡片。返回的 HTML 用 `DOMParser` 静态解析，不执行页面脚本，不播放课程视频、不提交答题、不发送学习完成请求。平台自身仍可能记录普通 GET 访问。

参考：[Chrome 脚本注入 API](https://developer.chrome.com/docs/extensions/reference/api/scripting)、[下载 API](https://developer.chrome.com/docs/extensions/reference/api/downloads)、[会话存储](https://developer.chrome.com/docs/extensions/reference/api/storage)。

## 权限与隐私

| 权限 | 用途 |
| --- | --- |
| `activeTab`、`scripting` | 用户点击扩展后识别课程标签页并读取课件 DOM |
| `storage` | 本机持久保存偏好；会话内保存课件与队列 |
| `downloads` | 发起、监控、暂停和取消扩展自身的下载 |
| `alarms` | 后台休眠后继续核对和推进下载队列 |
| `clipboardWrite` | 用户点击复制时写入文件链接，不读取剪贴板 |
| `declarativeNetRequestWithHostAccess` | 对本次下载的确切资源地址携带来源站点域名，处理防盗链 |
| 超星域名与 `cldisk.com` 的站点权限 | 跨 iframe 读取课件；访问平台提供的文件资源 |

不申请 `cookies`、`debugger`、`history` 或全站点权限。没有远程脚本、遥测、广告、上传接口或同步存储。完整说明见 [PRIVACY.md](PRIVACY.md)。

文件地址、课程名称等仍会暂存在本机的扩展会话存储中。Chrome 自身会保存正常的下载记录；扩展不清除这些记录。

## 常见问题

**扫描后没有文件？** 等预览加载完再扫描，或进入具体章节。只展示图片的页面不一定提供原文件。第三方嵌入域名和学校专有镜像域名暂不在支持范围。

**403 或链接过期？** 刷新对应课件、重新扫描，然后重试失败项。扩展会尝试刷新地址，并为 PDF 选择平台返回的 PDF 地址；不能保证无权限的文件可下载。

**目录扫描不完整？** 仅处理当前目录中可发现且可访问的章节。未加载的目录需要先在课程页展开。结构不同的旧版页面可尝试“当前页扫描”和多个标签页汇总。

**要求验证码或身份验证？** 在课程页面正常完成后重试；扩展不会自动完成验证。

**下载出的文件打不开？** 下载记录若 MIME 为 HTML/JSON，会报告失败，提示重新登录。服务器类型错误、文件损坏仍需自行检查。已经生成的错误文件不会被扩展自动删除。

**音视频支持到什么程度？** 只支持直接文件地址。暂不处理 HLS 分片拼接、DRM、直播、加密流或音视频转码。

**浏览器重启之后？** 偏好保留；扩展中的资源清单、签名与队列清空，需要重扫。Chrome 原生下载记录不受影响。后台服务工作线程暂时休眠则可从会话存储恢复队列。

**下载保存在哪里？** Chrome 默认下载目录下的“超星课件”文件夹，可在偏好中修改相对目录。扩展不能直接指定任意绝对路径；“每个文件询问保存位置”会依次显示保存对话框。

## 开发与验证

运行环境无第三方依赖；测试使用 `linkedom` 作为开发依赖。Node.js 20+：

```sh
npm ci --ignore-scripts
npm test
npm run check
npm run package
node scripts/package.mjs --source
```

- `npm test`：资源解析、URL 边界、脱敏、章节访问、版本选择和下载队列回归测试。
- `npm run check`：JavaScript 语法、清单资源、权限范围和常见敏感字段检查。
- `npm run package`：输出可解压加载的扩展 ZIP，只打包白名单文件。
- `--source`：另生成包含测试、脚本、README 与锁文件的源码 ZIP。
- `npm run icons`：使用本地脚本生成扩展图标。

文件结构：

```text
manifest.json          Chrome MV3 清单
manager.html           下载管理页面
src/core.js            解析、URL 与文件名处理、脱敏、版本选择
src/page.js            同源资源请求与章节读取
src/background.js      Chrome API、消息边界、下载来源规则
src/queue.js           可恢复的会话下载队列
src/manager.js         搜索、勾选、扫描与下载界面
src/styles.css         响应式界面
src/preview-demo.js    虚构数据预览，仅在非扩展环境使用
tests/                 纯合成数据测试，不包含真实课程信息
scripts/               语法检查、打包、图标生成
docs/TESTING.md         验证范围与手动验收步骤
```

`manager.html` 可用普通本地 HTTP 服务预览界面。非扩展环境会明确显示“界面示例”，使用虚构数据，不能真实下载课程。真实功能必须通过 Chrome 加载扩展。
